# Storefront 包说明

## 入口与公开契约

- `src/app` 是唯一 React 前端入口，承载品牌官网、用户中心、经销商中心和管理后台，禁止另建第二个前端应用。
- 公开产品、分类、内容、经销商和支持页面必须 SSR/预渲染，主要文本和链接存在于首个 HTML。
- 所有业务数据通过 `/api/v1` 获取；禁止直接依赖数据库包或在前端复制价格/授权规则。

## 体验方向

- 视觉聚焦真实产品、运动和家庭互动，使用明亮中性色、清楚排版、克制动效和少量高识别运动色块。
- 每次实现同时完成 Mobile/Tablet/Desktop；优先保证信息、CTA、键盘焦点和对比度。
- 页面模块从 CMS 契约渲染，不把运营文案和模块顺序硬编码为长期事实。

## 领域分工

- `features/public-site`：公开官网、产品、内容、经销商查找、支持和搜索。
- `features/account`：注册用户中心和 B2C。
- `features/dealer`：经销商 Dashboard、目录、快速下单、报价、订单、企业与团队。
- `features/admin`：全部运营后台模块。
- `features/platform`：国际化、SEO、同意管理、分析和全局壳。

## 完成要求

每个页面完成时覆盖加载、空、错误、权限、移动布局、键盘、SEO 和分析事件。产品、价格、库存、下载权限与账号类型的最终判断一律以后端响应为准。
