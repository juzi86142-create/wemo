# Public Site 前台模块

## 页面任务

- 全局：头部、移动抽屉、公告、搜索联想、账号入口、市场/语言切换、页脚。
- 首页：CMS 模块装配 Hero、分类、主推产品、玩法、品牌价值、经销商、质量安全、文章和订阅。
- 商品：产品总览/分类/新品、筛选排序分页、详情媒体/变体/价格/规格/玩法/下载/FAQ/推荐、最多四项比较。
- 内容与支持：玩法列表/详情、支持中心、FAQ、下载、联系、About、质量安全和法律页面。
- 经销商公开入口：地图/列表联动、门店信息、无结果引导和分步经销商申请。
- 搜索：产品、文章、FAQ、下载统一结果和无结果恢复路径。

## 路由范围

负责 `P-001`、`P-010` 至 `P-082` 的全部公开页面。公开商品、分类、内容和可公开经销商详情必须输出 SSR HTML、canonical、metadata、结构化数据与分析事件。

## 边界

不得写死经销商价格、库存可售判断、文件权限或推荐授权过滤。旧站 `www.wemovetoy.com` 的资产只在品牌确认后进入 CMS/媒体数据，不复制旧站 HTML。
