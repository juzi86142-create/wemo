# Contracts 包说明

## 角色

`@wemo/contracts` 是唯一跨前后端类型契约层，保存 API 输入输出、错误、分页、领域枚举与可序列化值对象。它不包含业务服务、数据库实现、React 组件或供应商 SDK。

## 公开契约

- 根 `src/index.ts` 是唯一公开入口；应用不得深层导入内部文件。
- 运行时边界使用 Zod schema，TypeScript 类型由 schema 推导，避免维护两份定义。
- API 破坏性修改必须版本化；字段命名、可选性、null 语义和金额单位不得由前后端各自解释。

## 领域目录

- `common`：ID、分页、错误与通用响应。
- `identity`：身份、角色和账户状态。
- `catalog`：产品与商品展示契约。
- `dealers`：经销商企业、申请与成员。
- `commerce`：金额、购物车/库存预占（服务端持久化在 Redis）、报价、订单、支付与售后状态。
- `content`：CMS、媒体、SEO、搜索、表单、本地化快照与通知模板/投递契约。
- `platform`：市场、语言、分析事件、审计、集成、作业、报表与平台配置契约。

契约落点以 `packages/database/prisma/schema.prisma` 与 API 模块为准：核心/支撑契约数据落 PostgreSQL；购物车、库存预占、地址本、订阅、数据请求、通知模板与投递、分析事件、集成配置、作业执行与报表定义/结果等持久化在 Redis（键前缀 `wemo:`；持久层键不设 TTL，仅真缓存可过期删除）。修改这些契约的持久化语义前先与 API 侧确认。

所有新增契约必须在所属目录 README 中补充用途，并添加解析成功/失败测试。
