# 01 工作流 AI 约束

## 开工必读

依次读取根 `AGENTS.md`、本目录 `README.md`、目标源码路径沿途的全部 `AGENTS.md`，再读取 `网站重构需求.md` 中本工作流列出的章节与 `docs/requirements-traceability.md` 对应行。现有模块 README 是待办，不是已实现证据。

## 修改边界

- 只直接实现本工作流拥有的 API 模块、前端子目录和共享包领域。
- 不在 Catalog 中计算价格或库存，不在 Search 中绕过 Catalog/Media 的发布和授权过滤。
- 需要 actor、任务、审计或供应商时依赖 04 的公开 port；需要企业范围时依赖 02；需要交易信息时依赖 03。尚未合并时使用符合相同契约的 fake。
- 不主动修改共享装配文件；把接入需求记录在交付说明，由 04 集成。若当前请求明确要求完成集成，可做最小追加，禁止顺手重排或格式化整个文件。

## 验证重点

测试必须从 HTTP、公开 application service 或实际 Next.js 路由进入，覆盖草稿不可见、市场/语言回退、预览越权、私有文件越权、索引过期降级和 SSR/SEO 输出。不得用直接调用内部方法或破坏状态不变量来宣称问题或功能成立。
