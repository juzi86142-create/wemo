# 04 工作流 AI 约束

## 开工必读

依次读取根 `AGENTS.md`、本目录 `README.md`、所有将被装配模块的 README/公开入口和目标源码路径沿途的 `AGENTS.md`。共享装配只连接已存在的公开能力，不替其他工作流猜测或补写领域规则。

## 修改边界

- 本工作流拥有横向能力和共享热点，但不得直接操作 01/02/03 的 repository；Settings、Reports 和 Jobs 均通过公开 service/port 协作。
- adapter 隔离供应商 SDK/DTO，密钥只读取环境或密钥引用。没有用户明确授权时，不连接真实外部写入服务，不发送邮件、不上传、不部署。
- 审计、分析、任务和日志分别处理安全记录、业务事件、异步执行和诊断信息，不能混成一个通用事件表。
- 集成共享文件时只做可审查的追加，保留其他工作流的现有改动；发现契约不一致时返回领域所有者修正，不在装配层加类型断言掩盖。

## 验证重点

通过真实启动入口验证 filter/interceptor/guard 顺序、request_id 和错误结构；通过消费者入口验证任务重入、幂等、失败明细和重试上限；通过后台 HTTP 验证报表与设置权限。全仓门禁通过后仍需把测试范围和未完成的人工验收如实写入追踪矩阵。
